# ⚡ NEON AIR SYNTH

Sintetizador y secuenciador gráfico interactivo con visión artificial y trazos de neón flotantes en realidad aumentada.

---

## 🚀 Cómo Iniciar el Proyecto

1. Haz doble clic en el archivo `start.bat` o ejecuta en la terminal dentro de esta carpeta:
   ```bash
   node server.js
   ```
2. Se abrirá automáticamente tu navegador en `http://localhost:3000`.
3. Haz clic en **ACTIVAR CÁMARA Y AUDIO** y concede permisos de cámara web.

---

## 🎮 Controles Gestuales

* **Pellizcar (Índice + Pulgar):** Dibuja trazos de neón flotantes en el aire.
* **Palma Abierta (1 segundo):** Abre la mano con los 5 dedos extendidos para borrar la pantalla con una explosión de partículas.
* **Segunda Mano (Control Expresivo):** La altura de tu segunda mano modula el filtro *Low-Pass* del sintetizador en tiempo real.
* *(Modo alternativo: También puedes usar el mouse/touch para dibujar si no deseas encender la cámara).*

---

## 🎁 3 Melodías Ocultas (Easter Eggs)

Dibuja estas formas geométricas en un solo trazo para desbloquearlas:

1. **🔺 Triángulo:** Desbloquea *Prisma Celestial* — Arpegio etéreo ascendente en modo lidio tipo Vangelis.
2. **🟩 Cuadrado:** Desbloquea *Cyber Groove 8-Bit* — Línea de bajo funky y sintetizador analógico.
3. **⭐ Estrella:** Desbloquea *Sinfonía Estelar* — Campanillas cósmicas y glissando espacial.
